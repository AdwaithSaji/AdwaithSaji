# Maintaining this profile

## Layout

```
README.md                         the profile page
assets/header.svg                 animated banner (hand-written SVG)
assets/footer.svg                 closing flourish (hand-written SVG)
assets/typing.svg                 typing strip      ┐ generated by
assets/card-*.svg                 project cards     ┘ scripts/build_assets.py
scripts/telemetry.py              renders the weekly contribution trace
.github/workflows/telemetry.yml   runs telemetry.py daily → `output` branch
```

Everything except the activity panel is served from this repo. The activity
panel is read from `output/telemetry.svg` via raw.githubusercontent.com; if it
is ever missing, GitHub shows its alt text and the rest of the page is unaffected.

## Editing

- **Card text, chips, typing phrases:** edit `CARDS` / `PHRASES` in
  `scripts/build_assets.py`, then `python scripts/build_assets.py`. The script
  refuses lines over 50 chars and chip rows that overflow the card.
- **Header / footer:** edit the SVG directly. Keep text in the font stacks already
  used; GitHub renders SVGs as images, so web fonts and scripts do not load.
- **New project card:** add an entry to `CARDS`, regenerate, and add a matching
  `<a><img width="400" alt="…"></a>` line in README.md. Keep cards in pairs.

## Preview locally

```
python scripts/build_assets.py
GITHUB_TOKEN=$(gh auth token) python scripts/telemetry.py --user AdwaithSaji --out dist/telemetry.svg
```

Open any `.svg` in a browser to watch it animate. For a GitHub-faithful render of
README.md, either push to a branch and view `README.md` on github.com (relative
asset paths resolve per branch), or POST the README to the GitHub API:
`gh api markdown -f mode=gfm -f context=AdwaithSaji/AdwaithSaji -F text=@README.md`.

Note: a local telemetry run uses your own token, so its totals can include private
contributions. The workflow uses `GITHUB_TOKEN`, so it only sees what your
public profile shows.

## Animation rules

- Motion lives inside the SVGs (CSS keyframes and SMIL). GitHub never runs JS.
- Every animated element honours `prefers-reduced-motion`. The static state is
  a complete design (first phrase typed, schematic without packets).

## Workflow

- Least privilege: read-only by default; `contents: write` only on the render job.
- Only one action is used (`actions/checkout`), pinned to a commit SHA. To update,
  look up the new tag's SHA:
  `gh api repos/actions/checkout/git/ref/tags/<tag> --jq .object.sha`.
- Scheduled workflows pause after 60 days without repo activity. Run it manually
  from the Actions tab (or push any commit) to resume.
